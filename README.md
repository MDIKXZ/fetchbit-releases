# Fetchbit Releases

This repository is the official public distribution point for Fetchbit release artifacts and updater metadata. The application source code is maintained separately and is not published here.

## What is Fetchbit?

Fetchbit is a desktop application for downloading media from supported platforms. It provides controls for choosing quality and downloading audio or video, includes Smart Cut for selected segments, and offers a modern desktop experience.

## Download

Install the latest available version from the GitHub Releases page:

**[Download the latest Fetchbit release](https://github.com/MDIKXZ/fetchbit-releases/releases/latest)**

## Updates

Official updates are signed and delivered through Fetchbit's built-in updater. Avoid downloading Fetchbit binaries from unofficial sources.

## Alpha and Preview Releases

Current releases may be Alpha or Preview builds. Bugs are expected, behavior may change between releases, and feedback is appreciated.

## Security

Official Fetchbit installers are published only through this repository's [GitHub Releases](https://github.com/MDIKXZ/fetchbit-releases/releases).

## Issues and Contributions

This repository is intended only for release distribution. Bug reports and source-code contributions belong in the private development repository, so Issues and Pull Requests here are not monitored.
